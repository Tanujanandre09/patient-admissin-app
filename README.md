# Ward Register – Patient Admission Management App

A web application for hospital staff to manage admitted patients.

## Tech Stack
- Frontend: React 18, Vite, JSX, CSS
- Backend: Python, FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy
- Validation: Pydantic

## Features
- Add new patients
- View patient records
- Search patients by name
- Filter by ward, department and doctor
- Edit patient details
- Delete patient records
- Discharge patients
- Responsive design for desktop, tablet and mobile

## Project Structure
- frontend/ – React application
- backend/ – FastAPI application
- docs/screenshots/ – Project screenshots

## Run Locally

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## Deployment

- Backend: Render
